# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [Unreleased]

### Added
- `read/` — актуальная веб-версия книги по главам и `book.epub` для скачивания, собирается из fb2 через fbc (fb2cng)
- `build_read.py` — скрипт сборки `read/`
- `assets/read-reader.js` — запоминание места чтения, кнопка «Продолжить чтение» и прогресс прочитанных глав в оглавлении (localStorage); перенос прогресса на другое устройство ссылкой `?sync=` или QR-кодом
- `assets/read-theme.css` — тема для чтения `read/`: светлая/тёмная по системе, адаптивный размер от телефона до ТВ, переносы
- `inject_epub_warning.py` — скрипт, добавляющий в старый `epub/` предупреждение со ссылкой на ту же главу в `read/`

### Changed
- `epub/` помечен как устаревший: на каждой странице предупреждение и ссылка на актуальную версию

## [2026-03-24]

### Added
- `context/index.md` — краткое описание каждой из 1432 глав, сгенерировано автоматически
- `context/sequences.md` — хронологический лог событий Последовательностей по всей книге
- `reader.html` — браузерный ридер fb2 прямо из репозитория
- `generate_context.py` — скрипт генерации/обновления context/ через qwen CLI

## [2026-02-21]
